Encoding a cover

Stegassette.encode() writes an entry table plus payload bytes into the RGB channels of a checkerboard of data pixels. Inline code keeps the size of its surrounding text and takes a hairline box — in an all-monospaced system it has nothing else to distinguish it. 

const encoded = Stegassette.encode({
  source,
  entries: [audioEntry],
  traversal: "serpentine",
  keymap: "mirror-x",
  border: 2,
});
