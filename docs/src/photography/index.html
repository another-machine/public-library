Shutter speed you do not have

A browser cannot set a camera's exposure time. What it can do is read frames, so a long exposure is assembled rather than taken: stack eight consecutive frames and the result carries eight frames of movement, eight frames of light, and about a third less sensor noise. Shutter time becomes a frame count over whatever rate the camera granted.

new Camera({ facingMode?: "environment" | "user"; width?: number; height?: number; frameRate?: number; followOrientation?: boolean; })

new Darkroom(canvas?: HTMLCanvasElement)

darkroom.expose(video: HTMLVideoElement, options: ExposeOptions): Promise<Exposure>

darkroom.develop(params: DevelopParams, scale?: number): void 

const camera = new Camera({ facingMode: "environment" });
const darkroom = new Darkroom(canvas);

await camera.start();
await darkroom.expose(camera.video, {
  frames: 8,
  trail: 0.55,
  stack: "mean",
  mirror: camera.mirrored,
});
darkroom.develop(params);
// Enable the camera to begin.

Two ways to stack

mean sums the frames by weight, so a moving subject spreads its light across everywhere it went and dims accordingly. max keeps the brightest value each pixel ever reached, so a moving light holds full intensity along its whole path — the difference between a blurred lamp and a light trail.

Parameters that know when they are inert

trail weights later frames more heavily, which only means something to mean. Under max there is no weight for it to bias, so the schema marks it inert and the control leaves. The same rule hides the halation tints when halation is off, and the split hues when split is zero.
